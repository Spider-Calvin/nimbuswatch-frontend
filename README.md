# nimbuswatch-frontend

Frontend for NimbusWatch (SRE monitoring system). React 19 + TypeScript + Vite.

## Setup

```bash
npm install
npm run dev
```

Dev server runs at `http://localhost:5173`. Set `VITE_API_URL` to point at `nimbuswatch-backend`.

## Stack

- React 19, TypeScript, Vite
- TanStack Router / Query / Table / Form (planned)
- Tailwind v4 + Shadcn UI (planned)
